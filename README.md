# NorthWitherControl

Небольшой плагин для Paper и Purpur, который блокирует появление Иссушителя. Он отменяет попытки создать моба, не вмешиваясь в обычные механики сервера, такие как взрывы, блоки и кастомные динамиты.

[Скачать JAR](https://github.com/donatikwin/NoWitherPlugin/raw/main/target/NorthWitherControl.jar)
## Возможности

- Блокирует появление Иссушителя, когда настройка `wither-disabled` включена.
- Управляет блокировкой командой `/nowither`.
- Сохраняет изменения настройки между перезапусками.
- Поддерживает перезагрузку конфигурации без перезапуска сервера.
- Предоставляет подсказки аргументов команды игрокам с правом администратора.
- Не использует фоновые задачи, циклы или таймеры.

## Требования

- Paper или Purpur с API версии 1.21 или новее.
- Java 21 или новее.

Плагин собирается с Paper API `1.21.4-R0.1-SNAPSHOT`. Совместимость конкретной сборки сервера следует проверить на тестовом сервере перед установкой в рабочую среду.

## Установка

1. Нажмите [«Скачать JAR»](https://github.com/donatikwin/NorthWitherControlPlugin/raw/refs/heads/main/target/NorthWitherControl.jar), чтобы скачать готовый файл плагина. Его также можно собрать из исходного кода по инструкции ниже.
2. Поместите JAR в папку `plugins` сервера.
3. Запустите или перезапустите сервер.
4. При первом запуске плагин создаст `plugins/NorthWitherControl/config.yml`.

По умолчанию появление Иссушителя заблокировано.

## Команды

| Команда | Описание |
| --- | --- |
| `/nowither true` | Запретить появление Иссушителя и сохранить настройку |
| `/nowither false` | Разрешить появление Иссушителя и сохранить настройку |
| `/nowither reload` | Повторно загрузить конфигурацию с диска |

Право на выполнение команды: `northwither.admin` (по умолчанию выдано операторам сервера).

## Конфигурация

```yaml
wither-disabled: true

messages:
  prefix: "&8[&bControl&8] &r"
  blocked: "&aПоявление Иссушителя заблокировано."
  unblocked: "&cПоявление Иссушителя разрешено."
  reloaded: "&aКонфигурация перезагружена."
  no-permission: "&cУ вас нет прав для выполнения этой команды."
  usage: "&cИспользование: /nowither <true|false|reload>"
```

Параметр `wither-disabled` задаёт поведение при запуске плагина:

- `true` — отменять попытки появления Иссушителя.
- `false` — не блокировать его появление.

Цвета сообщений задаются стандартными кодами Minecraft с символом `&`. После изменения файла примените новые значения командой `/nowither reload`.

## Как работает блокировка

Плагин слушает событие `CreatureSpawnEvent` с приоритетом `HIGHEST`. Когда событие относится к `WITHER` и `wither-disabled` включён, плагин отменяет событие через `setCancelled(true)`. Это предотвращает появление существа на уровне событий Bukkit/Paper, а не удаляет его уже после создания.

Блокируются новые попытки спавна, проходящие через это событие, в том числе призыв построенной конструкцией и командами, которые используют стандартный механизм спавна. У самого Minecraft нет ванильного яйца призыва Иссушителя; поведение кастомных предметов и других плагинов зависит от того, каким способом они создают моба.

Плагин не удаляет Иссушителей, появившихся до включения блокировки. Если другой плагин изменяет или отменяет события спавна, итоговое поведение может зависеть от взаимодействия между плагинами.

## Сборка из исходного кода

Для сборки требуются JDK 21 и Maven. В корневой папке проекта выполните:

```powershell
mvn clean package
```

Готовый файл появится здесь:

```text
target/NorthWitherControl.jar
```

Зависимость Paper API подключается со scope `provided`, поэтому API сервера не включается в JAR плагина.
